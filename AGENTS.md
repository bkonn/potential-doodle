# Project instructions

- Run `python3 -m unittest discover -v` after behavioral changes.
- Keep the starter dependency-free unless a feature requires otherwise.
- Never commit personal data, exported conversations, secrets, or runtime databases.
- Keep facts distinct from assumptions, with sources and confidence labels.
- Do not treat a plan or generated draft as a completed external action.
- Do not claim integrations, background activity, or message delivery without verification.
- Add explicit permission checks before implementing external actions.
